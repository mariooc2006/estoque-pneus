# Estoque de Pneus em C

Programa em C pra controlar o estoque de uma loja de pneus. Trabalho com pneus, entao resolvi fazer um projeto disso.

## O que ele faz

- cadastrar pneu (medida, marca, quantidade e preco)
- ver o estoque
- registrar compra
- registrar venda (nao deixa vender mais do que tem)
- mostrar o valor total do estoque

## Como rodar

```
gcc estoque.c -o estoque
./estoque
```

## O que aprendi

Struct, vetor de struct, funcoes, switch case e do while.
